# UI Design — Mobile-First Layout

All screens render as a mobile layout (max-width: 430px) centered on desktop.

```
Desktop view:
+----------------------------------------------------+
|                                                    |
|          +------------------------+                |
|          |                        |                |
|          |    Mobile UI (430px)   |                |
|          |                        |                |
|          +------------------------+                |
|                                                    |
+----------------------------------------------------+
```

---

## Shell Layout

Every authenticated screen shares this shell:

```
+--------------------------------+
|  Freelancer Manager      [pic] |  <- top bar (app name + avatar)
|================================|
|                                |
|                                |
|         Page Content           |
|         (scrollable)           |
|                                |
|                                |
|================================|
|                                |
|  Jobs    Daily    (+)   Off   Profile |  <- bottom nav
|  [ ]    Report   [FAB]  Day   [ ]    |
|                                |
+--------------------------------+
```

Bottom nav detail:

```
+--------------------------------------------+
|                                            |
|  +------+  +------+  +----+  +------+  +------+
|  | Jobs |  |Report|  | +  |  | Off  |  | Me   |
|  |  📋  |  |  📝  |  |    |  |  🗓  |  |  👤  |
|  +------+  +------+  +----+  +------+  +------+
|                        ^^^^
|                    FAB (floating)
|                    raised above bar
+------------------------------------------+
```

The (+) FAB opens a context menu based on current tab:

- On Jobs tab → "New Job"
- On Report tab → "New Report"
- On Off Day tab → "New Off Day"

## Navigation Flow

```
Bottom Nav
├── Jobs (default)
│   ├── Job List (hirer / employee filter)
│   └── Job Detail
│       └── Edit Job
├── Daily Report
│   ├── Report List (by date + job)
│   │   ├── [cp] per row → copy single report
│   │   └── [Copy All] → copy all reports for date
│   └── Export Excel
├── (+) FAB
│   ├── (on Jobs)    → New Job
│   ├── (on Report)  → New Report
│   └── (on Off Day) → New Off Day
├── Off Days
│   └── Off Day List (by month + job)
└── Profile
    ├── Edit Profile
    ├── Copy Template Config
    ├── Variable Mappings Config
    ├── Export Template Config
    └── Salary History
```
